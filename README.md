# Skillroom static website prototype

This package contains a responsive Skillroom workshop marketplace and a basic admin login/dashboard built with plain HTML, CSS and JavaScript.

## Open it

Double-click `index.html`. No installation is required.

## Demo admin login

- Email: `admin@skillroom.co.za`
- Password: `Skillroom123`

The login is intentionally a browser-only demonstration. It is not secure enough for a live website. Production admin authentication, permissions and data changes must be implemented on a server.

## Included interactions

- Responsive desktop, tablet and mobile layouts
- Category filters and workshop search
- Workshop details and save buttons
- Host enquiry form
- Demo admin login and dashboard
- Demo add-workshop and admin actions

All images are packaged locally so the prototype can be viewed offline.
